## What's new

- **Discord Rich Presence** shows the game you are playing while it runs.
- **No console window** opens behind a game.
- **Silent updates.** From this version on, updates download and install in the background, with progress in the sidebar.
- **N64 mode** setting under Graphics.
- **Update control** restyled; refresh buttons animate while they work.
- **Installer** uses Plaid branding.

## Known limitations

- Fullscreen, the window title, N64 mode, aspect ratio, resolution and controller bindings are saved by the launcher but not yet applied by the game runtime. Support is in development and will arrive as a recompiler update.
