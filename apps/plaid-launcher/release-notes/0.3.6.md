## What's new

- **One Plaid window.** Launching Plaid again brings the existing window forward, even when it is minimized.
- **Faster recompilation.** Plaid spends less time repeating ROM analysis and uses less memory on large builds.
- **Paper Mario gets further.** Plaid finds 381 map overlays automatically and reaches file select in a scripted run.
- **Pokémon Stadium 2 can boot.** Plaid compiles its compressed code modules and completes a 60-second native test without faults.
- **Smoother Rogue Squadron video.** Plaid now shows both interlaced fields correctly, fixing the back-and-forth motion in the intro.
- **Steadier Mario Party 2 validation.** The opening curtain stays steady during fast build checks.

## Known limitations

- Paper Mario gameplay after file select still needs testing.
- Resident Evil 2 and GoldenEye 007 still have startup blockers. Graphics issues remain in some games.
- The Windows installer uses a signed update manifest. Windows may still warn when opening the installer directly.
