## What's new

- **Much smaller installer and updates.** The installer is about 3 MB. Plaid downloads its recompiler (about 300 MB) once on first start and checks it before use; later app updates stay small.
- **Paper Mario builds again.** Builds use the full analysis by default, which the newer automatic repair step had broken for some games.
- **Publisher shows as sting-raider** in Windows' installed apps list.

## Known limitations

- The first start needs an internet connection to download the recompiler; Compile waits until it finishes.
- The installer is not code-signed, so Windows may warn before running it.
- N64 mode, aspect ratio, resolution and controller bindings reach the game but have not been checked on a real display or controller yet.
