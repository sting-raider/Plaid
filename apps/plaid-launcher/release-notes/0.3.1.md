## What's new

- **One-window installer.** Installing shows a single progress window and opens Plaid when it finishes, with no setup wizard.
- **Fullscreen with the game's name.** Recompiled games open fullscreen, titled with their name; recompile older builds to get this.
- Plus 3 fixes to the update panel and its error messages.

## Known limitations

- From the next update, updates download first and install when you restart Plaid; that flow has not run against a real release yet.
- N64 mode, aspect ratio, resolution and controller bindings reach the game but have not been checked on a real display or controller yet.
