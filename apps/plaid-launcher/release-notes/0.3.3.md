## What's new

- **Everything in one installer.** Plaid now installs its own recompiler and compilers; no Plaid checkout, Python, Rust or Git needed.
- **Setup asks only for your ROM folder.**
- **Games compile into Plaid's own data folder.** Recompile games built with earlier versions once.

## Known limitations

- The installer is about 250 MB, and app updates download the whole installer.
- Updates download first and install when you restart Plaid; that flow has not run against a real release yet.
- N64 mode, aspect ratio, resolution and controller bindings reach the game but have not been checked on a real display or controller yet.
