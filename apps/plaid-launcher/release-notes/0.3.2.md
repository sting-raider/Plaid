## What's new

- **Choose the install folder.** A first install asks where to put Plaid, then installs in one step; updates keep using that folder.

## Known limitations

- Updates download first and install when you restart Plaid; that flow has not run against a real release yet.
- Plaid installs per user, so folders that need administrator rights, such as Program Files, cannot be chosen.
- N64 mode, aspect ratio, resolution and controller bindings reach the game but have not been checked on a real display or controller yet.
