# Large RSP registries and linker arguments

The synthetic non-graphics RSP DPC contract now places 257 entries whose
matching first word leads to a stale exit at the same PC before the valid
text. The fixed mask failed with an unlowered IMEM entry. Registry-sized
retry state lets the task finish and produce the original register and DMA
results. The synthetic response-file check verifies the full argument list,
quoting, and cleanup for a command over the Windows length limit.

For the local RE2 diagnostic, the original visible native executable stops
at VI 215, fault 15 at `8004d348`. Capturing the enclosing function's first
fetch from pinned ares matches all 131,072 bytes of the native fault window.
A manually supplied replay-authenticated load covering the replaced prefix
lets CPU lowering proceed with three residual sites and five trapped
blockers. That map draws 300 RSP texts, which the parent refused. Removing
the registry limit alone exposed WinError 206 at the GCC invocation.

With both changes, the retained objects relink in 0.558 s for the headless
artifact and 0.513 s for the window artifact. The visible diagnostic reaches
VI 254, 18 PI transfers and a framebuffer setup, then faults 3 at
`80088194` targeting `8008819c`, before graphics tasks begin. The lowered
site loads its target from an indexed table. The experimental declaration
and game data stay local. Automatic replacement discovery and the remaining
control transfers are still open.
