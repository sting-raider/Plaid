# Independent lifetimes for replayed mapped fragments (ADR-0296)

The broad replay source that contains startup code also covers dormant code
candidates in the decompression destination. Its active native binding correctly
refuses the byte store at physical0x411c0. Deleting that guard would be unsafe.

A declared ares_tlb source may now select an aligned nonempty subrange of a
complete natural capture. Its virtual offset and physical offset must agree,
and its entire extent must remain inside that capture. The original anchor,
whole-ROM replay, source identity and authentication remain mandatory. Equal
bytes at another physical offset do not establish an executable alias. A fixed
capture cannot supply mapped text. No captured targets certify closure.

The native build policy partitions wholly executable mapped declarations at
4KiB virtual boundaries, retaining the complete extent of each known host
implementation. A proof-bearing table or tail cell stays in the same fragment
as its consuming transfer, including intervening pages. Missing consumer
metadata conservatively prevents partitioning. Ambiguous/stale declaration
identities cannot select placement metadata. Rediscovery recomputes all code
identities and proofs before lowering. Each resulting native source retains
its own mapping, content, generation and active-frame protections. No runtime
MIPS decoder, interpreter or JIT is added.

The synthetic complete-capture test composes two independent equal-byte
fragments around a natural anchor, verifies their slot identities, and rejects
crossed physical identities, fixed sources, bad alignment, empty, overflowing
and out-of-capture ranges. Layout tests distinguish the natural anchor from
the extracted interval. Policy tests cover exact identity, host/table extents,
distant consumers, tail cells, missing consumers, ambiguity and idempotence.
Retained full-state mapped continuation/delay/source contracts cover native
instruction effects and source lifetime refusal.

The retained production map supplied the exact363 load declarations after an
older worker checkout disappeared externally. It contains no indirect trace
observations. Partitioning produces635 declarations, including501 mapped
sources. Rediscovery grows49,250->49,374 blocks, with zero static blockers and
five residual sites retained. Native completeness remains false.

The visible silent prototype advances from VI0-1/fault2/PC80920a04 to
VI1/fault12/PC80801bbc, RA70000614. The latter is an MTC0 to Context (register4),
not an authorization to invent Context/BadVPN or general refill state. All
fourteen VI registers, framebuffer origin and graphics/audio task counts remain
zero. Readback PNGs depict uninitialized RAM, not a rendered logo or title.
